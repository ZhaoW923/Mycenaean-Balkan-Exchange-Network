# GIS Project Files

This folder contains the QGIS project developed during the spatial analysis phase of the research.

## Notes

  - Due to GitHub file size limits, the base map layer used in all versions was compressed into a ZIP file (`/QGIS/geoBoundaries/geoBoundariesCGAZ_ADM0.zip`).  
  - To fully load the project in QGIS, please download and extract the ZIP file, and ensure the extracted layer is located in the expected path as defined in the project file.  
  - Alternatively, you can re-link the raster manually when open in QGIS.
