# Mycenaean-Balkan-Exchange-Network
GIS and two-mode network analysis of Late Bronze Age bronze-related materials and Mycenaean-style artifacts across the Balkans.

## Repository Structure

- `Data/`: Raw and processed data tables, including site metadata, artifact records, and cultural features.
- `Figures/`: Output maps and summary tables used in the report and visualizations.
- `Gephi/`: Gephi project and source CSV files used for two-mode network visualizations.
- `QGIS/`: The QGIS project file used for spatial analysis.

## How to Use

- Open the `.qgz` files in QGIS.
- Use Gephi to explore the `.gephi` file and CSV node/edge data.
- Refer to the README files in subfolders for detailed notes.
